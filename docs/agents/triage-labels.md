# Triage Labels

The `triage` skill moves issues through a state machine using these labels:

| Label | Role |
|-------|------|
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | Fully specified, an AFK agent can pick it up |
| `ready-for-human` | Needs human implementation |
| `wontfix` | Will not be actioned |

All labels use the default naming convention. No custom overrides.
